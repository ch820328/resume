# Power Story 07: Baby Tracker (Learning & Product Mindset)
## 核心主題：快速學習 (Fast Learner)、用戶至上 (User First)、技術廣度 (Breadth)

### 🎭 轉化策略 (BQ Pivot Points)
*   **若問【快速學習新技術】**：重點放在你如何在兩週內自學 React Native 並解決跨平台適配（Web 與 Android）的挑戰。
*   **若問【用戶至上/解決痛點】**：重點放在你如何觀察到家人（長輩、父母）在溝通過程中的挫折，並用技術解決現實生活中的資訊不對稱。
*   **若問【非工作相關的技術熱情】**：展現你對開發的熱愛。

---

### 🚀 STAR Story

#### **1. 結論先行 (High-level Impact)**
為了改善家庭成員在照護新生兒時的溝通斷層，我利用業餘時間，在兩週內自學並開發了 **Baby Tracker 跨平台應用**。採用 **React Native** 實作了 Android 與 Web 端的一鍵同步。這個專案徹底解決了多位照顧者之間的資訊差，消除了 100% 的口頭詢問負擔，目前仍是我家庭日常運作的核心工具。

#### **2. 技術挑戰 (Tier - Architecture)**
這是一個麻雀雖小、五臟俱全的全棧專案：
*   **前端**：使用 **React Native** 配合 React Native Web，達成一套代碼跨平台運行。
*   **數據與同步**：整合 **Firebase** 實作實時訂閱與離線緩存，確保在醫院等網路不穩的地方也能正常紀錄。
*   **設計思維**：針對長輩使用者設計了「高對比、大按鈕」的 UI。

#### **3. 關鍵決策與 Leadership (Layer - Decision & Risk)**
*   **快速學習的策略 (Learning Strategy)**：面對全新的移動開發領域，我沒有漫無目的地看課程，而是採取 **「問題導向學習法」**。我先定義出三個核心功能：即時同步、離線儲存與跨平台適配。我透過分析開源專案與文件，在 48 小時內做出了第一版 Prototype。這種快速原型設計的能力，讓我在面對工作中的新技術挑戰時也能游刃有餘。
*   **用戶至上的細微觀察 (User First)**：在開發過程中，我觀察到太太在抱著嬰兒時只能單手操作手機。因此我 **決定重新設計整個互動路徑**，確保所有核心記錄功能都能在「單手握持範圍」內完成。這不是技術難題，而是 L4 工程師應有的產品敏感度。
*   **技術權衡 (Trade-off)**：在選擇 Flutter 與 React Native 時，考慮到我已具備 React 的基礎，為了 **「極大化交付速度」**，我選擇了 React Native。雖然 Flutter 的 UI 渲染更一致，但在這個特定情境下，速度與生態系的成熟度是我的首要考量。

#### **4. 結果與成果 (Result)**
*   **結果**：成功交付高品質產品，家庭溝通效率提升顯著。
*   **反思**：這個專案強化了我對 **「全生命週期開發」** 的理解——從需求定義、架構選型、UI/UX 到部署維護。
