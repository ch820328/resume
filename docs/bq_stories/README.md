## 💡 面試即時小提醒 (Quick Tips)

1.  **金字塔結構**：不管講哪個，先講結論（Impact）！
2.  **Leadership 訊號**：多講「我觀察到...我建議...我決定...」。
3.  **不要怕講細節**：但在講細節前，確保面試官已經理解你的架構 (Tier)。
4.  **轉身機制 (The Pivot)**：如果題目問 A 但你準備了 B，試著找連結點。
    *   *例如：問「失敗」，可以講 Reliability Guard 早期沒做 IaC 導致的混亂，以及你後來如何建立高標準。*
