# Behavioral Interview Stories Index
# 行為面試故事目錄

This directory contains categorized STAR stories for Google and Amazon interview preparation.
此目錄包含為 Google 與 Amazon 面試準備的 STAR 故事分類。

---

## 📂 Categories | 故事類別

### 1. [Googleyness & Ambiguity (文化契合度與處理模糊)](./cat1_googleyness_ambiguity/README.md)
Focus: Cultural fit, navigating uncertainty, and being helpful.
核心：文化契合度、在不確定性中前進、主動協助他人。

### 2. [Leadership & Influence (領導力與影響力)](./cat2_leadership_influence/README.md)
Focus: Ownership and influencing without formal authority.
核心：主人翁精神、發揮非職權影響力。

### 3. [General Cognitive Ability (GCA) (綜合認知能力)](./cat3_gca_problem_solving/README.md)
Focus: Problem-solving logic and technical depth.
核心：解決問題的邏輯與技術深度。

### 4. [Conflict & Teamwork (衝突處理與團隊協作)](./cat4_conflict_teamwork/README.md)
Focus: Emotional intelligence and handling disagreements.
核心：情商與如何處理意見分歧。

### 5. [Failure & Growth (失敗與成長)](./cat5_failure_growth/README.md)
Focus: Self-awareness and the ability to learn from mistakes.
核心：自我覺察與從失敗中學習的能力。

---

## 📝 How to use this folder | 如何使用此資料夾
1. Create a new Markdown file for each story inside the corresponding category folder.
2. Follow the STAR format (Situation, Task, Action, Result).
3. Update the main [Preparation Guide](../behavioral_interview_prep.md) checklist as you complete them.

1. 在對應的類別資料夾中，為每個故事建立一個新的 Markdown 檔案。
2. 遵循 STAR 格式（情境、任務、行動、結果）。
3. 完成後更新主 [準備手冊](../behavioral_interview_prep.md) 中的清單。
