**題目：描述你未來 5-10 年的職業目標。**

**回答：**
我的目標是成為一位 **「能夠在複雜系統中定義標準，並引導團隊解決系統性問題的資深技術專家 (Staff Engineer / Technical Lead)」**。

為了達成這個目標，我將階段性地深化以下能力：
1.  **未來 3 年：深耕系統架構與影響力**
    我希望在像 Google 這樣具備大規模數據與複雜基建的環境中，不僅是寫出高效代碼，更是要學會如何設計「可擴展、易維護」的系統架構。我想透過像 RFTool 或 Engineering Hub 這樣的專案經驗，學習如何在跨區域、多團隊的環境中推動技術標準。
2.  **未來 5-10 年：技術領導力與變革管理**
    我期望能領導更核心的基建專案，並能在技術選型與業務目標之間做出精準的平衡。我不僅想解決「今天的問題」，更想預見「後天的瓶頸」並提前佈局。同時，我非常享受指導與培養人才的過程，我希望能帶領出一支具備強大技術韌性的精英團隊。

**為什麼是 Google？**
因為這裡有全球最具挑戰性的問題。我認為只有在處理極端規模 (Scale) 的挑戰時，技術才真正具備改變世界的影響力。我希望能將我的「自動化與流程優化」熱情，貢獻給 Google 的核心工程文化。
