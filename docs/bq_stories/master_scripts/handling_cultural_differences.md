**題目：你如何處理因文化或個人差異引起的衝突？**

**回答：**
我處理文化或個人差異的原則是 **「擔任文化翻譯者，並尋找共同的技術語言 (Act as a cultural translator)」**。

在一項跨國協作專案中，我曾遇到兩位工程師因為 **「代碼審核 (Code Review) 風格」** 產生了嚴重衝突。其中一位同仁來自非常直率的文化，他的評論總是簡短且直白，例如「這不對」或「重寫這段」；而另一位同仁來自較為委婉的文化，他覺得自己受到了人身攻擊，進而開始消極配合。

我採取了以下行動：
1.  **分別進行「文化解碼」 (Validation & Reframing)**：我先與受挫的同仁溝通。我肯定他的感受，但也幫他重塑對方的意圖：「在對方的文化裡，『直率』是對代碼品質與你時間的尊重，並非在質疑你的能力。」
2.  **指導溝通風格的微調**：我也與那位直率的同仁私下聊。我建議他：「你的技術點 100% 正確，但如果能在評論中多加一個『為什麼』，對方會更願意接納你的專業意見。」
3.  **建立團隊的溝通約章 (Communication Guideline)**：我提議在團隊中建立一套 Code Review 規範，鼓勵大家用「詢問」代替「指令」，例如將「重寫」改為「我們如果嘗試 X 方案，會不會比現在更有效率？」

**結果**：
兩位同仁在理解了彼此的「溝通出發點」不同後，緊張關係迅速緩解，最終成為了非常信任的技術夥伴。這次經驗讓我體會到，在跨國團隊中，**「對溝通風格的同理心」與「技術能力」同樣重要**。我們不應該要求每個人都變得一樣，而是要學會「翻譯」彼此的差異，轉化為團隊的動力。
