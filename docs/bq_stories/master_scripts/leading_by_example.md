**題目：描述一次你以身作則 (Leading by Example) 的經驗。**

**回答：**
對我來說，以身作則不是指你要做最難的工作，而是要 **「在團隊遇到瓶頸或士氣低迷時，第一個跳進泥坑裡找答案」**。

在推動 **Issue Analytics (自動追蹤工具)** 時，團隊對這套工具的反彈很大。大家覺得這是額外的負擔。那段時間會議氣氛非常僵，大家都不想成為第一個被系統監控的人。

我採取的行動是：
1.  **把自己當成第一個「受試者」**：我沒有強迫別人先用，而是第一個把我的所有高風險專案、以及我負責的所有長期 Issue 全部放上儀表板。
2.  **公開透明我的失敗**：我故意在週會上展示我自己的「超期提醒」。我對大家說：「你看，連我也會漏掉這些事。這不是為了懲罰，而是為了幫我記住。」
3.  **轉化工具的角色**：當大家看到我透過系統提醒，避開了兩次差點導致延期交付的 Bug 時，他們開始意識到這不是「監視器」，而是 **「救命稻草」**。

**結果：**
我的行為降低了大家的焦慮。看到連發起人都在「被監督」，大家開始願意嘗試，並主動給我優化意見。最終這套工具成了團隊的標準配備。這次經驗讓我學到，**如果你想要求團隊改變，你自己必須是第一個改變的人**。
