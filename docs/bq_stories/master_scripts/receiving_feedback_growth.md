**涵蓋題目：**
*   收到建設性批評或負面回饋的經驗？
*   如何應對主管的負面評價？

**回答：**
面對負面回饋，我的態度是 **「抽離情緒，將批評轉化為可量化的行動計畫 (Fact-based Growth)」**。

在 **RFTool** 開發初期，我的主管曾在 1-on-1 中給了我一個相當沉重的負面評價。他認為我過於沉迷於架構的完美，導致第一版的交付時程嚴重落後，他甚至質疑我「是否分不清優先順序」。

我採取了以下行動：
1.  **冷靜接受並承認事實**：雖然當下心裡很受挫，但我沒有找藉口。我告訴主管：「謝謝你這麼直白。我確實太想把 Base Class 做得面面俱到，而忽略了現階段團隊急需上線的需求。」
2.  **制定「救火計畫」**：我當場提議將框架拆解為「最小可行性版本 (MVP)」，先確保核心測試能跑，再逐步優化。
3.  **定期同步進度**：在接下來的一個月中，我每週主動向主管回報「交付進度 vs. 長期重構」的比例，確保我的工作節奏與團隊目標完全對齊。

**結果：**
我們最終如期完成了測試任務，且主管在季度評估中特別稱讚我「具備極強的糾偏能力與心理韌性」。這次經驗讓我學到，**負面評價不是對我個人的否定，而是對我「當前方向」的導航修正**。作為資深工程師，最重要的能力之一就是能快速從錯誤中修正並重新出發。
