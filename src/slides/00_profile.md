# 面試備忘錄：個人簡介與核心競爭力 (Profile)

這張投影片的核心在於：**定位為「工程生產力」與「自動化」專家，強調解決組織瓶頸的價值。**

---

### 1. 💬 核心定位 (Core Positioning)

*   **🇺🇸 English:**
    "I am a Senior Software Engineer specializing in **Engineering Productivity**. My unique value lies in the intersection of high-level web platforms and low-level firmware automation. I don't just write code; I build the tools and platforms that enable hundreds of other engineers to work faster and more reliably. I have a proven track record of reducing manual processes by 90% and building scalable internal services from scratch."
    
*   **🇹🇼 中文:**
    「我是一位專注於 **工程生產力 (Engineering Productivity)** 的資深軟體工程師。我的核心價值在於銜接高階 Web 平台與底層韌體自動化的跨領域能力。我不僅僅是撰寫代碼，我更擅長構建那些能讓數百名工程師工作得更快、更可靠的工具與平台。我擁有將手動流程減少 90% 並從零開始構建可擴展內部服務的成功經驗。」

---

### 2. ❓ 關鍵數據解析 (Key Metrics)

1.  **「90% 手動轉數位化提速 (Manual-to-Digital Speedup)」**:
    *   這主要來自於 **PIC Transcript** 與 **GitLab CD** 專案。將原本需要人工肉眼辨識 BIOS 或手動刷機的流程，完全轉化為自動化流水線。
2.  **「5+ 內部平台構建 (Internal Platforms Built)」**:
    *   包含：OpenClaw (AI 審核), Issue Analytics (數據治理), RFTool (測試框架), Central Dashboard (監控)。
3.  **「5+ 內部跨部門服務同步 (Internal Dept Services Sync)」**:
    *   強調解決「資訊孤島」的能力，例如透過 **Issue Analytics** 同步全公司不同單位的數據與資源。

---

### 3. 🎯 給面試官的記憶點 (Takeaways for Interviewer)

*   **跨棧能力 (Full-stack Depth)**: 從 React 到 C 韌體都能應對，代表能處理複雜的端到端 (End-to-End) 系統問題。
*   **平台思維 (Platform Thinking)**: 不只是解決單一 Bug，而是建立「制度」與「工具」來防止 Bug 再次發生。
*   **對品質的追求 (Quality Driven)**: 所有的自動化都圍繞著「正確性」與「一致性」展開，符合 Google 對基礎設施穩定性的要求。
