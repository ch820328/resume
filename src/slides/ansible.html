Stress Test Environment Automation (Ansible)

Web Service Testing
Challenge: [EN] In distributed stress testing, we needed 10 machines to fire requests simultaneously. However, inconsistent tool versions and library drift led to messy performance data, making it impossible to identify real system bottlenecks.
[TW] 在分布式壓測中需要 10 台機器同時發起請求，但各機器的工具版本不一導致數據偏誤，無法準確定位系統瓶頸。
Solution: [EN] Developed an Ansible-based automation script to manage all 10 load generators. Every node undergoes an identical setup—from OS variables to Python environments—guaranteeing perfect consistency for every test run.
[TW] 透過 Ansible 將 10 台壓測機的環境設定完全自動化，從系統參數到 Python 環境確保 100% 一致。
Impact: [EN] Shrunk environment setup time from 1 hour to 5 minutes. Achieved high-reliability test data, enabling the successful identification of performance regressions in high-concurrency scenarios.
[TW] 部署時間自 1 小時降至 5 分鐘。獲得高信賴度的壓測數據，成功抓出高併發下的效能瑕疵。
