Baby Tracker: Distributed Sync App

Full-Stack / Local-First
Challenge:
  • High latency and sync conflicts occurred when caregivers logged data simultaneously
  • Existing apps suffered from poor offline UX and race conditions in weak networks
Solution:
  • Built a Local-First architecture with an Optimistic UI for zero-latency interactions
  • Engineered a custom Sync Protocol using Optimistic Locking to handle concurrent offline edits
Impact:
  • Eliminated sync conflicts and data loss during intermittent network drops
  • Reduced data sync latency to <100ms, guaranteeing a consistent real-time view across devices
