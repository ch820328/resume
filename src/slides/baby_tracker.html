Baby Tracker: Distributed Sync App

Full-Stack / Local-First
Challenge: Real-time synchronization of baby activity data across multiple caregiver devices with offline support and conflict resolution. Existing apps had high latency and poor offline UX.
Solution: Developed a Local-First architecture using SQLite/IndexedDB and a custom Sync Protocol. Implemented WebSockets for instant updates and Optimistic UI for zero-latency interactions.
Impact: Reduced data sync latency to <100ms. Achieved 100% data integrity during network intermittent periods. High user satisfaction for seamless caregiver collaboration.
