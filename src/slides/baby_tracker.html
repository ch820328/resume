Offline-First Baby Activities Tracker

Full-Stack Integration & Data Sync
Challenge: [EN] Designing a multi-user sync system where caregivers could log data on spotty networks without version conflicts or UI lag on older devices.
[TW] 在網路不穩的環境下，解決多人共同記錄數據時的同步衝突，並確保在舊型手機上操作依然流暢。
Solution: [EN] Selected **WatermelonDB** for its high-performance **JSI adapter** to handle local storage. Developed a **Node.js** backend with **Redis-based locking** and **Prisma** to manage atomic updates and family-level data isolation.
[TW] 選用具備 **JSI 同步機制** 的 **WatermelonDB** 提升本地存取效能。後端使用 **Node.js** 配合 **Redis 鎖** 與 **Prisma**，實作原子性更新與家庭數據隔離。
Impact: [EN] Built a reliable system that guarantees **100% data integrity** across devices. Validated through **Artillery load testing** and **IDOR security audits** to ensure a safe and stable environment for family data.
[TW] 建立可靠的同步架構，保證多端數據 100% 一致。並通過 **Artillery 壓測**與防越權審計，確保系統在高負載下的穩定與安全。
