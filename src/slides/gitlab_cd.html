Infrastructure as Code & GitOps (CD)

Release Engineering & DevOps
Challenge: Production deployments were manual "black box" operations, lacking audit trails and easy rollback capabilities. Scaling to multi-environment (Dev/Staging/Prod) was a nightmare.
Solution: Implemented a **GitOps-driven CD Pipeline** using **Terraform** and **GitLab Environments**. Automated the entire provisioning and deployment flow with zero-downtime strategies.
Impact: Achieved **100% auditable deployments**. Reduced deployment-related incidents by **60%**. Enabled instant rollback capability, drastically improving system availability.
