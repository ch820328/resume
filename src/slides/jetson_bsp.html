Embedded BSP Factory (NVIDIA Jetson)

Embedded System Engineering
Challenge: Developers faced fragmented environments and complex manual CLI steps for NVIDIA BSP builds, leading to inconsistent images and high failure rates during environment setup.
Solution: Architected a **Dockerized Build Service** to encapsulate all BSP dependencies and toolchains. Developed a **Unified Portal** that replaces manual commands with a streamlined API, ensuring a standardized build process.
Impact: Eliminated **manual monitoring and environment setup overhead**. Achieved **100% build reproducibility** via isolated Docker containers. Freed up developer resources to focus on core feature development.
