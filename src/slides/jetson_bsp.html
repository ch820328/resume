Embedded BSP Factory (NVIDIA Edge AI)

Embedded Systems & Manufacturing
Challenge: Manual Jetson BSP builds faced high SKU fragmentation and 5GB+ image bottlenecks. "Manual BCT edits" for different memory vendors (RAM Code) risked catastrophic hardware bricking during mass deployment.
Solution: Architected a Full-Stack BSP Factory using Go (Gin) to orchestrate NVIDIA L4T builds. Integrated Zstd compression to optimize UPH and implemented SKU-aware automation for dynamic RAM Code/BoardID injection.
Impact: Increased Factory UPH by 25% via Zstd-accelerated image delivery and parallel MassFlash (MFI) orchestration. Eliminated 100% of bricking risks through automated SKU-validation guardrails.
