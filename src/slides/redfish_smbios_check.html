Redfish SMBIOS Consistency Checker

Infrastructure Validation
Challenge: "Silent configuration drift" in data center servers caused unexpected performance drops. Inconsistent BIOS settings across hundreds of nodes made hardware performance data unreliable and root-cause analysis time-consuming.
Solution: Engineered an automated scanning tool using the Redfish API to fetch and validate SMBIOS settings across the fleet concurrently. Implemented Python's asyncio with Exponential Backoff to maximize scan speed without overwhelming BMC control planes.
Impact: Transformed a manual, days-long audit process into an automated, minutes-long fleet-wide scan. By establishing a bit-level "Golden Standard" for configuration, we greatly reduced silent regressions and significantly improved the reliability of our tail latency metrics.
