RFTool: Modular Framework Refactoring

Platform Engineering & Refactoring
Challenge: [EN] As RFTool scaled to hundreds of test cases, high code redundancy and tight coupling with legacy hardware tools led to massive maintenance overhead and slow deployment cycles.
[TW] 隨著 RFTool 擴展至數百個測試案例，高度的代碼冗餘以及與舊版硬體工具的強耦合，導致了巨大的維護開銷與緩慢的部署週期。
Solution: [EN] Elevated RFTool from a simple reporting wrapper to a Full-Lifecycle Automation Framework. Integrated Robot Framework Built-in libraries for robust resource cleanup and implemented custom Listeners for real-time test monitoring and error recovery.
[TW] 將 RFTool 從簡單的報告外殼提升為 全生命週期自動化框架。整合了 Robot Framework Built-in 函式庫 以進行穩健的資源清理，並實作自定義 Listeners 進行即時測試監控與錯誤恢復。
Impact: [EN] Achieved a 50% reduction in test development time and eliminated 60% of redundant code. Transformed "Post-mortem" reports into "Active" lifecycle management, significantly improving hardware testing reliability.
[TW] 達成測試開發時間 減少 50% 並消除了 60% 的冗餘代碼。將「事後報告」轉型為「主動生命週期管理」，顯著提升了硬體測試的可靠性。
