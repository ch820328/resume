RFTOOL: Validation Framework Refactor

Tooling Engineering & Refactoring
Challenge: A legacy validation tool had become unmaintainable due to spaghetti code and lack of modularity. Adding support for new Redfish features took weeks of effort.
Solution: Refactored the core engine using **Object-Oriented Design Patterns** (Strategy, Factory). Implemented a **Plugin Architecture** that allows team members to add new validators easily.
Impact: Reduced code complexity by **50%**. Accelerated feature development time by **3x**. Improved developer experience for the internal validation team.
