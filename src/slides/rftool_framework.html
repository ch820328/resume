RFTool: Modular Framework Refactoring

Platform Engineering & Refactoring
Challenge: [EN] As RFTool scaled to hundreds of test cases, high code redundancy and tight coupling with legacy hardware tools led to massive maintenance overhead and slow deployment cycles.
[TW] 隨著 RFTool 擴展至數百個測試案例，高度的代碼冗餘以及與舊版硬體工具的強耦合，導致了巨大的維護開銷與緩慢的部署週期。
Solution: [EN] Architected a **Modular Test Framework** integrated with **Robot Framework**. Extracted 30+ core functions into a shared `library/`, implemented multi-inheritance interfaces (`Inheritor` pattern), and standardized hardware protocols (IPMI/Redfish) for long-term scalability.
[TW] 架構與 **Robot Framework** 整合的模組化測試框架。將 30 多個核心功能提取至共用的 `library/`，實作多重繼承介面 (`Inheritor` 模式)，並將硬體協議（IPMI/Redfish）標準化以確保長期的可擴展性。
Impact: [EN] Reduced new test development time by **50%** and eliminated **60% of redundant code**. Enabled seamless migration to modern Redfish/SAA tools while providing structured diagnostics via standardized JSON interfaces.
[TW] 將新測試開發時間縮短 **50%**，並消除了 **60% 的冗餘代碼**。在提供標準化 JSON 診斷接口的同時，實現了向現代 Redfish/SAA 工具的無縫遷移。
