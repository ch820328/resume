Secure Python Execution in UEFI (Python.efi)

Firmware Security
Challenge: [EN] Intellectual property (IP) risk in the EFI Shell environment. Python scripts were exposed as plain-text, and standard .pyc files were easily decompiled, leading to high exposure of proprietary logic.
[TW] EFI Shell 環境中的智財權 (IP) 風險。Python 腳本以明碼暴露，且標準的 .pyc 檔案極易被反編譯，導致核心邏輯面臨外洩風險。
Solution: [EN] Engineered a Secure In-Memory Decryption pipeline. Implemented a custom encryption tool for the shell and modified the python.efi interpreter to decrypt and execute source code directly in RAM.
[TW] 實作了安全記憶體解密流水線。開發了 Shell 環境下的自定義加密工具，並修改 python.efi 直譯器，使其能直接在 RAM 中解密並執行源碼。
Impact: [EN] Successfully secured critical engineering IP without compromising automation flexibility. Prevented unauthorized logic modification and reverse engineering in the pre-boot stage.
[TW] 在不犧牲自動化靈活性的前提下，成功保護了關鍵工程 IP。防止了 Pre-boot 階段的未授權邏輯修改與反編譯。
